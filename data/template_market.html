Notes for the build 🛠

🎨

Banners are composited

Magic Eden's public API doesn't expose banner assets, so each banner is generated from that collection's own item art — blurred bed plus a row of sharp tiles. Swap for real banners when you have an API key.

✅

The data is real

Every floor, ask, mint, seller and rank came from keyless public calls. Artwork is the creators' own, pulled from on-chain metadata and embedded so the page works offline.

⚖️

Placeholder art, not shippable art

These are other people's collections, fine for an internal sketch and standard practice for mockups. Swap them for your own launches before anything goes public.

🧩

Two fill paths

Listings with no auction-house account are AMM/pool asks and fill through a different instruction. The table's last column shows which is which. Branch on it.

🔒

Static, by design

No wallet, no signing, no live prices. Making it real needs Next.js + wallet-adapter on your own domain — see the repo README.

🔄

Refresh it yourself

python fetch_wide.py then python gen_market.py. Edit SYMBOLS to change which collections appear.
